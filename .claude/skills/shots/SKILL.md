# Кадры экранов

Тесты не видят то, что видит глаз: наложения, обрезанный текст, перенос суммы,
слипшиеся отступы. Правка интерфейса без просмотра кадров не считается проверенной.

1. `tool/shots.sh [фильтр]` — `flutter test test/shots/` с настоящими шрифтами
   (Outfit, Material Icons) на заполненной демо-данными базе. Кадры — в
   `build/shots/<экран>-<тема>-<язык>-<ширина>.png`. Фильтр — часть имени экрана.
2. **Открой PNG инструментом Read и посмотри** — каждый кадр затронутого экрана в
   обеих локалях: русский текст длиннее английского.
3. Проверяй правила вёрстки spec.md §8.0: суммы и кнопки с суммой не переносятся,
   обрезается название; ленты уходят до края экрана; отступы между карточками;
   контраст на стекле; ничего не прячется под панелью вкладок.
4. Переполнения ловит сам прогон: `tester.takeException()` в каждом кадре.
5. На устройстве (заказчик): `flutter run -d <id>`; системные вещи (клавиатура,
   уведомления, Face ID) кадрами не проверяются.
6. Отчёт: команда, число кадров, список просмотренных и что на них видно.

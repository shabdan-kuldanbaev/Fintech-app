# Fintech

Личные финансы для одного человека: расходы и доходы по счетам, календарь обязательных платежей
(кредиты, кредитные линии, подписки, коммуналка) с напоминаниями, бюджеты по категориям, накопления.
Flutter, iOS, локальная база, любая валюта, интерфейс на английском и русском.

Главная идея: единственный источник правды — транзакции. Оплата кредита или подписки — это тоже
транзакция, поэтому обязательные платежи сразу видны в расходах месяца, а Главная показывает не только
«потрачено», но и «сколько ещё обязан заплатить».

- Спецификация — `docs/spec.md` (первична).
- Ход работ — `docs/PROGRESS.md`.
- Правила для исполнителя — `CLAUDE.md`.
- Дизайн и инструменты переносятся из Flashcards-1.0 (Jattap), см. `docs/spec.md` §2.1 и §8.0.

Ограничения по замыслу: подключения к банкам и разбора СМС нет (в Кыргызстане нет открытого банковского
API, iOS не читает СМС) — весь ввод ручной; данные лежат локально и не шифруются, Face ID — замок экрана;
резервная копия — JSON через системный share sheet.

## Отклонения от спецификации

### Этап 1
- **Проверка на устройстве не выполнена**: в среде исполнителя нет macOS/Xcode. Критерий «запускается
  на iPhone» и `flutter build ios --no-codesign` (§13.3.1) — за заказчиком.
- **DAO слиты с репозиториями** (§10 перечисляет `daos/*`): запросы пишут репозитории
  `features/*/data/` поверх `AppDatabase`; менеджеры drift выключены (`build.yaml`). Слоёв меньше,
  граница I13 та же — presentation не видит drift.
- **Без riverpod_generator**: провайдеры объявлены вручную; `riverpod_annotation` и генератор убраны
  из зависимостей — меньше codegen, те же провайдеры.
- **`parseAmount`**: ровно три цифры после последнего разделителя при `minorUnits < 3` — разделитель
  групп («1,234» = 1234), иначе лишние знаки — отказ. В §4.1 этого не было; без правила «1,234»
  отвергалось бы.
- **Перенос из Flashcards**: `docs/learn/` не перенесён (учебник по коду Flashcards), из `docs/rules/`
  взят только `10-agent-workflow.md` (на него ссылаются скиллы). Скилл `shots` переписан под кадры из
  `flutter test` вместо симулятора (симулятора в среде нет); `tool/shots.sh` — на этапе 5.
- **§12.2 (НБКР) не проверен**: сеть контейнера не пускает на nbkr.kg (403 на прокси). Разбор
  пишется по известному формату `CurrencyRates/Currency[@ISOCode]/Nominal/Value` с запятой в числе и
  проверяется на фикстуре; подтвердить на устройстве.
- Стражи I1–I20 проверены мутацией: 18 стражей, на подложенных нарушениях красные все 18.
